# 阶段五 E8：AOO 五策略 × LLM 增益系数映射表

> 交付物类型：方法学透明化文档（纯 ADDITIVE，零 solver 数值改动）。
> 目的：明确 LLM 输出（结构化调制）的三个增益系数如何调制 AOO 五策略的算子参数，
> 使双引擎协同（stage1 蓝图）的因果链对审稿人可审计，避免"黑箱增益"质疑。

## 1. LLM 结构化输出的三个增益系数（stage1 mutate 蓝图）

LLM 经 `parse_contract` / `structured_modulate` 解析后产出三个标量增益（离线代理：
offline_structured_modulate 基于问题特征启发式生成；联网路径由 DeepSeek 生成，见阶段三）：

| 增益系数 | 含义 | 默认调制方向 |
| --- | --- | --- |
| `levy_gain` | Lévy 飞行步长增益 | 放大/缩小 Lévy 飞行的搜索半径 |
| `diff_gain` | 扩散传播增益 | 调制水传播 / 动物传播的扩散强度 |
| `explore_bias` | 探索偏置 | 调制风传播的全局探索概率 `windPm` |

## 2. AOO 五策略与增益系数的调制映射（基于 aoo_engine.m 实际耦合）

| 策略 | 机制 | 受哪个增益调制 | 调制语义 |
| --- | --- | --- | --- |
| 1. Lévy 飞行 | 重尾步长全局跃迁 | `levy_gain` | 增益↑ → 步长尺度↑ → 跳出局部更激进 |
| 2. 水传播 | 邻域扩散（流体） | `diff_gain` | 增益↑ → 扩散半径/强度↑ → 局部精细化 |
| 3. 动物传播 | 中程跳跃扩散 | `diff_gain` | 增益↑ → 跳跃幅度↑ → 中程探索 |
| 4. 风传播 | 全局随机漂移至随机解 | `explore_bias` | 增益↑ → `windPm`↑ → 全局探索概率↑ |
| 5. 萤火虫 | 向更优解吸引（局部收敛） | 无（自适应基准，由相对适应度驱动） | 不受增益直接调制，作收敛兜底 |

## 3. 诚实性约束（与阶段三/四一致）

- 增益系数由 LLM 结构化调制产生；离线态（`DEEPSEEK_API_KEY` 缺失）下为
  `offline_structured_modulate` 的启发式代理，**非 DeepSeek 真实输出**。论文不得宣称
  "online LLM tuned operator X by Y%"（见 `results/tevc_llm_gain/env_manifest.json`）。
- 三增益→五策略的调制是**线性/乘性缩放算子参数**，不改变算子数学定义，属策略层参数自适应，
  不引入新数值假设（零回归，门禁 [6] 已覆盖默认两目标主链竞争力）。
- 第 5 策略（萤火虫）作为相对适应度驱动的收敛兜底，不挂增益，避免增益叠加导致探索-利用失衡。

## 4. 单测建议（可选，未强制本期执行）

可新增轻量断言（门禁 [21] 占位）：`levy_gain/diff_gain/explore_bias` 三者任一变化时，
对应策略的算子参数（Lévy 尺度 / 扩散半径 / `windPm`）随之单调变化，且五策略集合恒为 5 个
（无策略被增益归零）。该断言属 ADDITIVE 健壮性校验，可在后续轻量补丁中加入。
